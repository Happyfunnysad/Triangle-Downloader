# Triangle Downloader

**Русский** · [English](README.en.md)

Расширение для Chrome (Manifest V3), которое добавляет кнопку ▽ прямо в плеер YouTube и
позволяет скачивать открытое видео, аудио и субтитры — перехватывая поток самого плеера.
Без `yt-dlp` и сторонних сайтов: вся работа происходит локально в браузере. Наружу уходят
только запросы функций, которые вы сами включили: SponsorBlock и закадровый перевод.

Поддержать меня можно на Boosty: https://boosty.to/triangle_black/

![Скриншот меню Triangle Downloader](docs/screenshot.png)

## Возможности

- **Видео** — 720p / 1080p в `.mp4` (видео + звук).
- **Аудио** — `.mp3` (только звуковая дорожка).
- **SponsorBlock** — автоматическое вырезание спонсорских вставок, саморекламы и
  напоминаний «подпишись» из скачанного файла по данным краудсорсинговой базы
  [SponsorBlock](https://sponsor.ajay.app/). Включается/выключается в меню
  (по умолчанию включено). Запрос к API приватный (k-анонимность: отправляется только
  префикс хеша ID видео, а не сам ID).
- **Выбор фрагмента** — поля «начало — конец» в меню (по умолчанию `0:00:00` … полная длина
  ролика). Загружается **только выбранный отрезок**, а не всё видео целиком: например,
  10 секунд из середины часового ролика скачиваются за пару секунд.
  Фрагменты **до 60 секунд** режутся точно по указанному времени (короткое
  перекодирование, примерно равное длине отрезка). Более длинные сохраняются мгновенно,
  но начало выравнивается по ближайшему опорному кадру (может быть на пару секунд раньше)
  — иначе точный старт невозможен: кадры между опорными хранятся как разница и не
  декодируются в одиночку.
- **Параллельная загрузка длинных видео** — диапазон делится на фрагменты по 10–15 минут,
  которые захватываются одновременно в нескольких фоновых вкладках (до 4), а затем
  склеиваются в один файл. Число вкладок выбирается автоматически (длительность, память,
  ядра CPU) или вручную в меню. Панель прогресса показывает состояние каждого фрагмента,
  общий прогресс и оценку времени; есть «Пауза», «Отменить» и «Повторить ошибочные».
  Ошибка или зависание одной вкладки перезапускает только её фрагмент.
- **Субтитры** — `.txt` без таймкодов. Приоритет — русский язык, иначе доступный.
- **Формат видео** — «Быстро» (VP9 в mp4 без перекодирования, секунды) или «H.264»
  (перекодирование для совместимости со старыми плеерами, медленно).
- **Авто-отключение автовоспроизведения** — расширение само выключает «Автовоспроизведение»
  YouTube, чтобы следующий ролик не запускался сам.
- **Закадровый перевод (VOT)** — озвучка чужого языка голосом Яндекса прямо в скачанном
  файле. Выключен по умолчанию; когда включён, ссылка на видео уходит на сервер Яндекса,
  который готовит дорожку (обычно пара минут — перевод запрашивается сразу и готовится
  параллельно с захватом). Три режима: «Поверх» (оригинал тише + перевод), «Вместо»
  (только перевод) и «Дорожка» (обе дорожки в mp4 с пометкой языка). Языки перевода —
  русский, английский, казахский. «Живой голос» — нейросетевые голоса Яндекса, требует
  входа в аккаунт (окно логина открывает Яндекс, пароль расширение не видит) и работает
  только для перевода на русский. Если Яндекс отвечает `402` (так он встречает запросы
  из-за пределов СНГ), в настройках можно включить сторонний ретранслятор — тогда ссылка
  на видео пойдёт через чужой сервер. Не сложилось с переводом — файл всё равно
  сохраняется, просто без него.

## ⚠️ Требования

- **Google Chrome** (или Chromium-браузер) с поддержкой Manifest V3.
- **Включённый блокировщик рекламы** (например, [uBlock Origin](https://ublockorigin.com/)).
  Это важно: без него YouTube вставляет рекламные вставки прямо в медиапоток, из-за чего
  захват может работать нестабильно или прерываться.

## Установка

1. Скачайте этот репозиторий (кнопка **Code → Download ZIP**) и распакуйте, либо
   `git clone`.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа вверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку **`extension/`**.
5. Откройте любое видео на `youtube.com` — в правой части панели плеера появится
   кнопка ▽ (**Triangle Downloader**).

## Использование

1. Нажмите кнопку ▽ в плеере — откроется меню.
2. При необходимости задайте **начало** и **конец** фрагмента (по умолчанию — весь ролик).
3. Выберите, что скачать:
   - **Видео** → `1080p` или `720p`;
   - **Аудио** → `MP3`;
   - **Субтитры** → `.txt`.
4. В секции **SponsorBlock** можно отключить вырезание рекламных вставок
   (по умолчанию включено; вырезаются категории sponsor, selfpromo, interaction).
5. Для видео можно переключить **Формат**: «Быстро» (по умолчанию) или «H.264».
6. Прогресс отображается во всплывающем окне; готовый файл сохраняется через стандартную
   загрузку браузера.

## Как это работает

YouTube в вебе раздаёт HD не одним файлом, а по протоколу **SABR**: видео и звук идут
раздельными зашифрованными потоками, которые плеер расшифровывает и склеивает в памяти
через Media Source Extensions. Готовой ссылки на файл не существует, поэтому расширение
подключается там, где данные уже расшифрованы и разложены по дорожкам:

1. **content_hook.js** (запускается до плеера) перехватывает медиасегменты в
   `SourceBuffer.appendBuffer`. Чтобы вшитый `ffmpeg.wasm` мог их обработать, плеер
   склоняется к кодеку **VP9** (AV1 он не декодирует).
2. Для скачивания расширение ставит нужное качество и **перематывает видео к краю
   загруженного буфера**, пока не соберёт все сегменты выбранного отрезка (без ускоренного
   проигрывания — мягко для YouTube).
3. **background.js** запрашивает у SponsorBlock список сегментов для вырезания
   (если вырезание включено).
4. **offscreen.js** запускает `ffmpeg.wasm` и собирает итоговый файл (по умолчанию — быстрая
   склейка `-c copy`; для `.mp3` и режима «H.264» — перекодирование). Сегменты SponsorBlock
   вырезаются на этом этапе: в режимах с перекодированием — фильтрами `select`/`aselect`
   (покадровая точность), в быстром режиме — нарезкой на куски со stream-copy и склейкой
   через concat demuxer (границы выравниваются по опорным кадрам).
5. **Субтитры** берутся из встроенной панели «Расшифровка видео» (текст уже отрендерен в
   DOM), поэтому не нужны никакие токены и перехват сети.

## Ограничения

- Захват идёт через перемотку буфера, поэтому для очень длинных роликов занимает время,
  пропорциональное длине.
- Режим «H.264» и `.mp3` перекодируют средствами `ffmpeg.wasm` (однопоточный) — это заметно
  медленнее быстрой склейки, вплоть до нескольких минут на длинных видео.
- В режиме «Быстро» файл `.mp4` содержит кодеки VP9/Opus — он открывается в Chrome, VLC и
  современных плеерах; для старых плееров используйте «H.264».
- Вырезание SponsorBlock в режиме «Быстро» происходит без перекодирования, поэтому границы
  вырезаемых вставок выравниваются по опорным кадрам и могут отличаться от разметки на
  пару секунд. В режимах «H.264» и `.mp3` вырезание точное. Если API SponsorBlock
  недоступен или для ролика нет разметки, файл сохраняется целиком.
- Финальная сборка идёт в `ffmpeg.wasm` (32-битный WebAssembly) с потолком памяти ~2 ГБ,
  поэтому итоговый файл больше ~1.5 ГБ не соберётся: 4 часа реальны в 720p или H.264,
  но не в 1080p «Быстро». Стыки фрагментов в режиме «Быстро» выравниваются по опорным
  кадрам (возможен сдвиг на секунды); в H.264 и MP3 — точные.
- Работает на страницах `youtube.com/watch`.

## Компоненты сторонних разработчиков

`extension/vendor/ffmpeg/` содержит сборки [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm):
пакеты npm `@ffmpeg/ffmpeg@0.12.10` и `@ffmpeg/core@0.12.6` (однопоточная сборка, не требует
cross-origin isolation).

Клиент закадрового перевода в `extension/vot.js` использует протокольные детали из
[VOT - Voice Over Translation](https://github.com/ilyhalight/voice-over-translation)
(MIT).

Данные о сегментах предоставляет [SponsorBlock](https://sponsor.ajay.app/) —
краудсорсинговая база рекламных вставок (лицензия данных CC BY-NC-SA 4.0).

Подробности по сторонним компонентам: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
